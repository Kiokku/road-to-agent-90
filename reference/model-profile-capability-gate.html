01 · Objects

三种对象，三种职责

对象 关键字段 作用
ModelProfileDefinition id、label、baseUrl、modelId、apiKeyEnv 服务端管理的规范化连接配置。
CapabilityReport profileId、checks 记录真实能力检查观察到的结果。
ModelOption id、label 可以安全交给模型选择器的最小对象。

02 · Gate

唯一的通过公式

valid definition
AND server-side secret exists
AND capability report exists
AND every required check is true
→ available

otherwise
→ rejected with reasons
Fail closed

未检查、缺配置、缺密钥或任意能力失败，都不可选。

03 · Capabilities

Week 02 的五项必要检查

  • responses能调用 Responses endpoint 并读取响应。
  • typed_streaming能按 type 区分语义流式事件。
  • function_calling能发出工具请求并接收配对结果。
  • structured_errors失败能被程序稳定识别。
  • cancellation应用取消后请求能停止并返回可判定结果。
