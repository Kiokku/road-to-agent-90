## 课程设计结论

后续每个 Lesson 建议固定为四层：

1. **Source Reading**：选 1 篇主课和最多 3 篇补课，只截取与当前 Week 成果有关的部分。
2. **Bridge**：说明原课程的 Python/通用 Agent 示例如何映射到 TypeScript、Node、React 与 Responses-compatible API。
3. **Project Practice**：只实现当前 roadmap 的一个 Workbench 成果，不另建无关教程 Demo。
4. **Verify & Explain**：把来源课程的练习改成项目测试、演示证据和闭卷复述。

具体 API、平台价格和 2026 年仍在变化的能力不能只依赖该仓库。生成对应 Lesson 时必须用官方一手资料复核。

## 明确保留的补充来源

- Week 02：Packy 与 OpenAI 官方 API 文档和真实 capability probe。
- Week 04：Web SSE、`AbortController` 与 React 状态管理的一手资料。
- Week 06：Étiquette Style Source、WCAG 与响应式 Web 验收资料。
- Week 10：Cloudflare Pages Direct Upload 与 Wrangler 官方文档。
- Week 12：本项目自己的 README、架构、失败案例、简历描述和模拟面试证据。
