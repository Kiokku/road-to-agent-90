## Direction

Hub 采用 Étiquette 的克制、温暖、精确气质：骨白色纸张/灰泥背景、炭褐文字、陶土锈色强调、细分隔线与充足留白。首屏强调使命与当前行动，主体使用开放式课程轨道，不采用卡片墙、Kanban 或彩色进度仪表盘。

## Intentional implementation deviations

- Concept lower page used a placeholder stating no Learning Records; implementation must show the seven records that already exist in the repository.
- Week names and current focus come from `docs/12-week-roadmap.md`; generated concept copy never overrides repository facts.
- Progress is derived from verified evidence files, not from decorative percentages or browser checkboxes.
